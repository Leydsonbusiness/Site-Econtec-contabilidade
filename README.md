# Econtec Contabilidade
Site institucional desenvolvido para a Econtec Contabilidade,
com foco em presença digital, responsividade e experiência do usuário.

## Tecnologias utilizadas
- React.js
- JavaScript
- CSS3
- Vite
- Git e GitHub
- Vercel (deploy)

## Funcionalidades
- Interface responsiva para diferentes dispositivos.
- Navegação intuitiva entre as seções do site.
- Integração com WhatsApp
- Apresentação dos serviços contábeis e empresariais.
- Exibição de avaliações de clientes por meio de carrossel e widget do Google Reviews.
- Seção interativa de perguntas frequentes (FAQ).
- Depoimentos de clientes
- Otimizações de SEO
- Componentização com React
- Identidade visual personalizada para a empresa.
